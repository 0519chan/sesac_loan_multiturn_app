# 전세자금대출 AI 상담 챗봇

국민은행, 신한은행, 하나은행의 전세자금대출 상품설명서 PDF를 근거로 답하는 상담 챗봇입니다.
새싹(SeSAC) 생성형 AI 과정에서 만든 실습 프로젝트입니다.

## 무엇을 하나

- 사이드바에 금융 프로필(희망 은행, 대출 목적, 연소득, 신용점수, 희망 전세금, 희망 대출액)을 넣거나 채팅으로 직접 묻습니다.
- 질문과 관련된 상품설명서 조각 4개를 찾아, 그 근거로 답합니다. 근거가 부족하면 "확인 필요"라고 쓰도록 지시합니다.
- 답변은 3턴 고정 구조입니다.
  1. 판정 요약, 근거, 쉬운 용어 설명, 다음 확인 질문
  2. 옵션 비교, 추천안, 쉬운 용어 설명, 추가 확인 질문
  3. 실행 계획(체크리스트), 필요 서류, 주의할 위험, 마무리 안내

## 구조

| 파일 | 역할 |
| --- | --- |
| `rag.py` | PDF 로드(PyMuPDF), 600자 단위 분할(100자 겹침), OpenAI `text-embedding-3-small` 임베딩, Chroma 저장과 검색(k=4). 조각마다 은행 이름을 메타데이터로 붙입니다 |
| `app.py` | Streamlit 화면, LangChain `ChatOpenAI` 스트리밍 응답, 대화 이력 유지 |
| `config.py` | 모델 이름, PDF 경로, 시스템 프롬프트 |

## 실행

```bash
pip install -r requirements.txt
```

1. `.env` 파일에 `OPENAI_API_KEY`를 넣습니다. `.env`는 커밋하지 않습니다.
2. `config.py`의 `FINETUNED_MODEL`에 사용할 모델 이름을 넣습니다(비어 있으면 실행되지 않습니다).
3. 실행합니다.

```bash
streamlit run app.py
```

처음 실행하면 `./data/`의 PDF로 검색용 저장소(`./jeonse_chroma`)를 만들고, 다음부터는 그것을 다시 씁니다.

## 고친 것

- 2026-11: `config.py`의 PDF 경로 목록에서 쉼표가 빠져 국민은행과 신한은행 경로가 한 문자열로 붙어 있었습니다. 두 파일을 찾지 못해 하나은행 문서만 검색 대상에 들어가던 문제를 고쳤습니다. 이미 만들어진 `./jeonse_chroma` 폴더가 있다면 지우고 다시 실행해야 세 은행 문서가 모두 들어갑니다.
